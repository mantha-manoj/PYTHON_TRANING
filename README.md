# 🐍 Python Full Course - 45 Days Training

> A structured Python training repository designed for beginners to advanced learners. This course covers Python fundamentals, problem solving, file handling, exception handling, modules, object-oriented programming, and hands-on practice.

| Details | Information |

| Duration | 45 Working Days |
| Mode | Instructor-Led Training |
| Level | Beginner to Intermediate |
| Language | Python 3.x |
| IDE | Visual Studio Code |
| Version Control | Git & GitHub |

# 🎯 Course Objectives

After completing this training, students will be able to:

- Understand Python fundamentals
- Write clean Python programs
- Solve programming problems
- Work with strings, lists, tuples, dictionaries and sets
- Use functions and modules
- Handle files and exceptions
- Understand Object Oriented Programming
- Build a strong foundation for Data Science, AI, Automation and Web Development

# 🚀 How to Run

Clone the repository

```bash
git clone https://github.com/your-username/Python-45-Days-Training.git
```

Move into the project

```bash
cd Python-45-Days-Training
```

Run a program

```bash
python filename.py
```

or

```bash
py filename.py
```
