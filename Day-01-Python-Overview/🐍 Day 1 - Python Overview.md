# 📖 What is Python?

Python is a **high-level**, **interpreted**, **general-purpose**, and **object-oriented** programming language. It is designed with a simple and readable syntax, making it one of the easiest programming languages to learn.

Python allows developers to build everything from small scripts to enterprise-level applications.

---

# 📜 History of Python

- Python was created by **Guido van Rossum**.
- Development started in **1989**.
- First public release was in **1991**.
- Python is maintained by the **Python Software Foundation (PSF)**.
- The name "Python" was inspired by the British comedy show **Monty Python's Flying Circus**.

# ⚖ Why Python?

| Python | C | Java |
|---------|---|------|
| Easy Syntax | Complex | Moderate |
| Less Code | More Code | More Code |
| Beginner Friendly | No | Moderate |
| Interpreted | Compiled | JVM Based |
| Huge Libraries | Limited | Good |

### Example

### C

```c
#include<stdio.h>

int main()
{
    printf("Hello World");
    return 0;
}
```

### Python


Python programs are shorter, cleaner, and easier to understand.

# 🛠 Installing Python

Download Python from the official website:

https://python.org

During installation:

- Select **Add Python to PATH**
- Click **Install Now**

Verify installation:

```bash
python --version
```

or

```bash
py --version
```

---

# 💻 Installing Visual Studio Code

Download Visual Studio Code:

https://code.visualstudio.com

Install the following extension:

- Python Extension (Microsoft)

---

# 📂 Python File Extension

Python source files are saved using the `.py` extension.

Example:

```text
hello.py
```

---

# ▶ Running a Python Program

Open Terminal or Command Prompt.

Run the program:

```bash
python hello.py
```

or

```bash
py hello.py
```

# 🖨 The `print()` Function

The `print()` function is used to display output on the console.

Example:

```python

print("My Name is Rahul")
print("Today is Day 1")
```

### Output

```text
Welcome to Python
My Name is Rahul
Today is Day 1
```
